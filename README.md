# Hospitality Business Skills

Six AI teammates for Hawaiʻi hospitality businesses (tour operators, attractions, lodging, transportation, restaurants-as-experiences). Each takes a URL and produces a markdown or HTML artifact you can paste into a project, share, or screenshot.

Built for the Nutmeg Labs seminar at HUB Coworking Kakaʻako (May 6, 2026) by [Lights On Digital](https://lightson.co).

## What's inside

Six skills, one per stage of the Lights On Guest Journey:

| # | Stage | Skill | Input | Output |
|---|---|---|---|---|
| 0 | **Context** | [Business Context](./business-context/SKILL.md) | Your URL | Markdown profile (paste into any AI project): overview, ideal guest, source markets, four forces, voice, comp set, differentiator |
| 1 | **Discover** | [Findability Check](./findability-check/SKILL.md) | Your URL | AI-search visibility audit: 5 LLM prompt simulations, schema check, 3 ranked fixes |
| 2 | **Book** | [Booking Edge](./booking-edge/SKILL.md) | Your URL | Triangulation report: review voice, comp parity, 3 evidence-tied conversion fixes |
| 3 | **Pre-arrival** | [Pre-Arrival Concierge](./pre-arrival-concierge/SKILL.md) | Your URL | 3-touch sequence (T-7 / T-1 / T+0) with upsell map (top 5 add-ons) and anxiety map |
| 4 | **Experience** | [Experience Pulse](./experience-pulse/SKILL.md) | Your URL | Quarterly market sweep across reviews, Reddit, blogs, YouTube, comps, industry trends → 3 service-change recs |
| 5 | **Reconnect** | [Repeat Hooks](./repeat-hooks/SKILL.md) | Your URL | 4-touch lifecycle drip + 3 reactivation emails + 3 referral mechanics |

Run **Business Context** first. Every other skill reads what it produces and reuses it.

## How to run a skill

Pick a skill above. Open Claude (claude.ai), ChatGPT, or Gemini — any AI assistant with web access works. Paste this:

```
Run the Business Context teammate using https://github.com/lightson-digital/hospitality-business-skills/blob/main/business-context/SKILL.md on https://kahukufarms.com
```

Replace the skill name and the URL with your own. The AI will read the methodology, run the audit, and return a markdown document you can paste into any AI project.

## How to install permanently

For Claude users:

1. Create a Claude Project named "Hospitality Business Skills"
2. Open each `SKILL.md` file from this repo, copy the full contents, paste into the Project's Custom Instructions
3. Open a new chat in that Project, give it a URL, and run

You now own the teammate. No one else can change it. Whoever owns the skill file owns the workflow.
